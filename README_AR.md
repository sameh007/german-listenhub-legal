# رفع صفحات الخصوصية على GitHub Pages (مرة واحدة)

الملفات هنا: `index.html` و`privacy.html` و`terms.html` و`support.html` و`delete-account.html`. كل صفحة بالعربي والإنجليزي وفيها زر تبديل اللغة.

1. ادخل على https://github.com وسجّل دخول.
2. اضغط **New repository** (زر + أعلى الصفحة).
3. الاسم: `german-listenhub-legal`، واختار **Public**، ثم **Create repository**.
4. اضغط **uploading an existing file**، واسحب الملفات الخمسة (ما عدا هذا الملف لو حابب) ثم **Commit changes**.
5. روح **Settings ← Pages**. تحت Build and deployment اختار **Deploy from a branch**، الفرع `main` والمجلد `/ (root)` ثم **Save**.
6. استنى دقيقة ثم حدّث الصفحة. هيظهر رابط الموقع، شكله:
   `https://اسم-المستخدم.github.io/german-listenhub-legal/`
7. افتح الرابط في المتصفح وجرّب الصفحات الأربع من الموبايل والكمبيوتر، بالعربي والإنجليزي.
8. ابعت لي الرابط، وأنا أضعه في التطبيق في الخطوة 15A.
